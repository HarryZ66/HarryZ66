### Featured work

**[SchoolFish: GreatSchools Guided Agent](https://github.com/HarryZ66/greatschools-guided-agent)** · AWS Breaking Barriers 2026, Top 4 of 80 teams
A school-search agent built for GreatSchools with a team of five. Claude on Amazon Bedrock AgentCore calls MCP tools through AgentCore Gateway over OpenSearch hybrid search, and plain code, not the model, checks each family need against the data. Guarded by a 38-case conversation eval suite and deployed with AWS CDK.

**[ReelMatrix](https://github.com/HarryZ66/reelmatrix)** · [live demo](https://reelmatrix.vercel.app)
An AI marketing strategy copilot. It started at the TestSprite Hackathon 2026 as a 3-agent Claude system (generate, critique, refine; [hackathon version](https://github.com/HarryZ66/TS-Hackathon-HZ-DL)) and grew into a strategy tool with review gates and a cross-model auditor. Next.js and TypeScript, live on Vercel.

**LLM reliability research** · co-first author, two manuscripts under review
Evaluated 7 open-weight models on 37,884 prompts with deterministic, hash-pinned inference, and calibrated an LLM-as-judge to 99.5% agreement with human labels.

**Admission Check for Agents** · AWS-sponsored capstone, in progress
An open-source pipeline that vets an agent or MCP server before approval: it scans tool definitions, sandbox-runs the agent behind AgentCore Gateway, and drafts least-privilege Cedar policies.
